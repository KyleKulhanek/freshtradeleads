# Contributing

FreshTradeLeads is an archived experiment rather than an actively maintained
product. Small, focused fixes and documentation improvements are welcome.

1. Fork the repository and create a topic branch.
2. Install development dependencies with `pip install -e '.[dev]'`.
3. Add or update tests and run `pytest`.
4. Confirm no source workbooks, reports, databases, customer/order data,
   credentials, private endpoints, or advertising identifiers are included.
5. Open a pull request describing the behavior and verification performed.
